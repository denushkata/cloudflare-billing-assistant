How it works

  1. Your dataUsage, plans, invoices and credit memos as CSV, or the built-in sample.
  2. Code calculatesProration, overage, discounts, tax and credits, in exact cents. Every amount comes from here.
  3. AI explainsWorkers AI (Llama 3.3) explains each issue, a likely cause and a fix. It never does math; replies that add numbers or links are discarded.
  4. MemoryA Durable Object per customer keeps every issue, decision and audit event. A repeat issue gets a “Seen before” suggestion.
  5. You decideResolve or escalate, with a note. Resolutions are final and recorded with your name.

Assignment requirements: LLM = Workers AI · coordination = the Worker and Durable Objects · user input = this page · memory = Durable Objects.
Runs on Cloudflare Workers, Workers AI and Durable Objects. Amounts are computed in code; the model only writes explanations.
